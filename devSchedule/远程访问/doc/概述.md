# 远程访问 — 概述(DSH-Mod 脱敏同步版)

> 背景读物,不是入口;状态与下一步只看[里程碑-远程访问.md](里程碑-远程访问.md)。完整版在私有外层仓库。

## 定位

让一台正在运行的 DSH 能被手机安全地远程使用:电脑照常启动 DSH(本体永远只听 `127.0.0.1`),手机打开网关地址,配对一次即可像在电脑上一样操作;覆盖局域网与 Tailscale。连接地址缓存在手机本地,可增删改。

## 关键设计决策(均已在实现中定案)

1. **网关而非改绑本体**:插件 host 半边自起 `0.0.0.0:<GW_PORT>` 反代 loopback 本体——不碰上游 CLI 对 `--host 0.0.0.0` 的安全拦截,自带鉴权层。
2. **鉴权**:固定配对码(自动生成或 `DSH_MOD_GATEWAY_CODE` 自定义)+ 32B 令牌(只存 sha256,HttpOnly cookie 一年)+ 全量吊销(码不变)+ `/mod-gateway/auth` 令牌换 cookie(跨地址/丢 cookie 静默恢复)+ 限速与跨站拒绝。
3. **特权边界(双层)**:网关镜像上游 `PRIVILEGED_METHODS` 直接 403;**唯一豁免** `settings.describe`(只读、Web 客户端启动必需),经网关鉴权后以 loopback 面目定向转发(上游 fence 将特权方法连受信 Host 也钉死 loopback)。转发保留原始 Host,上游 fence 是第二道防线。
4. **壳**:网关自带 `/mod-gateway/` 连接管理页充当"App"(加主屏幕);Capacitor 出真 APK 为后续路线。
5. **WS 代理**:手写(`http.request` 管道 + `net` 直转 upgrade,握手原样重放),零运行时依赖。

## 与其他系统的关系

- 实现代码在本仓库(`lib/gateway.js`、`lib/index.js`);回归测试在外层私有仓库 `tests/`。
- 上游 deepseek-harness 只读依赖:升级可能移动 `PRIVILEGED_METHODS`/fence 行为,须回归测试(尤其特权拦截与 settings.describe 豁免)。
