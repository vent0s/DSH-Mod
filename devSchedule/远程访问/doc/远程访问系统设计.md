# 远程访问系统设计(DSH-Mod 脱敏同步版)

> 状态:已实现并自动化验证;真机(非 loopback 来源)应用事件流问题未解,详见里程碑。完整版在私有外层仓库。

## 1. 目标(用户视角)

电脑照常启动 DSH;手机(局域网或 Tailscale)打开网关地址,配对一次,之后即可像在电脑上一样操作这台 DSH。地址缓存在手机本地;电脑上一个操作可踢掉所有已配对设备。

## 2. 架构

```text
手机浏览器(连接管理页 + DSH Web UI)
   │  http://<电脑地址>:<GW_PORT>(局域网/Tailscale)
   ▼
DSH-Mod 网关(0.0.0.0:<GW_PORT>,与 DSH 同进程,lib/gateway.js)
   ├─ /mod-gateway/*  自管:配对/令牌/吊销/轮换/auth/health/连接页/诊断
   └─ 其余全部 ──────── 反代(HTTP 管道 + WS 握手原样重放,保留原始 Host)
   ▼
DSH webserver(始终仅 127.0.0.1:<DSH_PORT>;上游 CLI 明确禁止 0.0.0.0)
```

- 启用:`DSH_MOD_GATEWAY_PORT` 导出即启用,未设置则零行为。`DSH_MOD_GATEWAY_BIND`(默认 0.0.0.0)、`DSH_MOD_GATEWAY_TARGET`(默认 `127.0.0.1:$DSH_PORT`)、`DSH_MOD_GATEWAY_CODE`(自定义配对码)、`DSH_MOD_GATEWAY_DIAG=1`(排障:注入 `window.__diag` 录制器与页面浮层、upgrade 时序日志;不记录请求/响应体与 cookie 值)。
- 启动脚本需把本机 IPv4(含 Tailscale)以 `--trusted-host <ip>` 传给本体,普通 RPC 因此通过上游信任 fence。

## 3. 安全模型(三层)

| 层 | 机制 |
|----|------|
| 1. 配对/令牌闸(网关) | 无令牌请求(含 WS)止步网关(页面 302/401,WS 断开)。令牌 32B base64url,cookie HttpOnly+SameSite=Lax+1 年,服务端只存 sha256。配对码固定(自定义或自动生成);`/rotate` 显式轮换并吊销;`/auth` 用手机本地备份的令牌静默换 cookie。跨站拒绝 + 每 IP 10 次失败锁 120 秒 |
| 2. 特权镜像名单(网关) | 凭据、设置变更、预设管理、原生目录/路径操作、`llm.discoverModels` 一律 403;唯一豁免只读 `settings.describe`(客户端启动必需)以 loopback 面目定向转发 |
| 3. 上游 Host fence | 反代保留原始 Host,上游把远程来源判为非 loopback:普通 RPC 因 trusted-host 放行、特权钉死 403;未声明 Host 依旧 403(DNS-rebinding 防线完好) |

红线:本体只听 loopback;无令牌请求永不到达 `/api`;密钥与配置变更面远程恒不可达。

## 4. 网关自管端点

| 路径 | 说明 |
|------|------|
| `GET /mod-gateway/` | 连接管理控制台 |
| `GET /mod-gateway/health` | 在线探测(CORS `*`,返回 `{ok,service,name}`) |
| `GET /mod-gateway/state` | 当前来源是否已配对(含 hostId) |
| `GET/POST /mod-gateway/pair` | `{code}`(GET 可带 `?code=`)换令牌;响应含 token+hostId 供本地备份 |
| `POST /mod-gateway/auth` | `{token}` 令牌换 cookie |
| `POST /mod-gateway/revoke` | `{code}` 吊销全部令牌(码不变) |
| `POST /mod-gateway/rotate` | `{code}` 换新码并吊销全部令牌 |

## 5. 已知限制与未解问题

- 明文 HTTP:定位家庭/个人 Tailscale 网,勿暴露公网。
