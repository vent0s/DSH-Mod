# 仓库状态跟踪 — 概述

DSH-Mod 已有会话标题栏动作和通用 RPC 通道，可在不修改 Harness 本体的情况下显示当前工作区的多个仓库。当前安装通过符号链接引用本地 DSH-Mod，Host 代码变更需要重启后加载。

工作区根目录不一定是 Git 仓库，因此配置保存在该目录的 `.dsh-repos.json`，使用相对路径；agent 只需修改同一份文件。默认本地检查每 60 秒，远端检查最多每 5 分钟，均由可见页面按需触发。Host 共享缓存并合并并发请求，不为每个页面创建独立后台轮询。

未提交统计包含暂存、未暂存及未跟踪文件；向上/向下计数是当前分支相对其配置上游的提交差异。未配置上游、分离 HEAD、网络失败必须明确显示未知或检查失败，不能显示成完全同步。fetch 仅更新远端引用，不执行 pull、merge 或 push。
